# rules/

Doctrine and definitions for the Evidence Work kit live **in this folder**.

The owner drops additional docs here. Files in `rules/` explain how register
fields are meant to be read. They are **not a second source of truth**.

- Scores, risks, status, and labels live only in `data/register.csv`.
- Do not re-score, reword, or add risks here.
- Do not treat this folder as a register, a write surface, or live-state.

| File | What it is |
| --- | --- |
| `scales.md` | Collapse / Uncertainty / Test effort scale, and how `Priority cue` is derived. Static. |
| _(owner-dropped)_ | Further definitions the owner adds over time. |
