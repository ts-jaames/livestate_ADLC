# M5 — The value lives in AI capability itself, not in the lifecycle wrapper

## Risk
Statement: The value lives in AI capability itself, not in the lifecycle wrapper. If the marginal value is the model, not our lifecycle, we're building a container around value we didn't create.
Category: Value
Gate: Define
Area: Definition (meta)

## Assumption(s)
### A1
Statement: We believe that people shown a model-only demo and an ADLC-gated progress surface (this repo's client board) will name the lifecycle/gating as the reason they would change how they staff or buy delivery — not the model alone.
Success criteria: Of 5 reviewers who did not build this board, at least 4, when asked "If you could keep only one, which would change how you run an engagement?" choose the ADLC-gated surface and write a reason that names confidence, slice, or gate — not model quality.
Failure criteria: 2 or more of 5 choose the model-only demo, or choose the board but give a reason that only names the model (speed, IQ, demo wow) with no gating/lifecycle term.

## Slice(s)
### S1 (tests A1)
Method: Two artifacts, same sitting, order randomized per person: (1) a 3-minute model-only capability demo using whatever model the firm already uses (unknown: which model — do not specify a vendor); (2) the live client board at whatever URL is currently deployed, with no sales script. Each person answers one forced-choice question and one written reason. Score reasons against a pre-agreed list of lifecycle terms vs model-only terms.
Type: Value
Execution: Requires manual run
Scope / time-box: n=5; 15 minutes per person; no new product built.

## Signal
Success signal: ≥4 of 5 choose the ADLC-gated surface and cite gating/confidence/slice in the reason.
Failure signal: ≥2 of 5 choose model-only, or choose the board with a model-only reason.
Threshold: Failure → Iterate or Stop further investment in ADLC-as-wrapper until a different value claim is framed. Success → value is not solely the model for this sample; still not a commercial close (see G5).
