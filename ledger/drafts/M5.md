# M5 — The value lives in AI capability itself, not in the lifecycle wrapper

## Risk
Statement: The value lives in AI capability itself, not in the lifecycle wrapper. If the marginal value is the model, not our lifecycle, we're building a container around value we didn't create.
Category: Value
Gate: Define
Area: Definition (meta)

## Assumption(s)
### A1
Statement: We believe people who see a model-only demo and this client board will say they would change how they run an engagement because of the gating — not because of the model alone.
Success criteria: Five people who did not build this board. At least 4 of 5, asked "If you could keep only one, which would change how you run an engagement?", pick the board. Their written reason names proof, a slice (the smallest test), or a gate — not how smart or fast the model is.
Failure criteria: 2 or more of 5 pick the model-only demo. Or they pick the board but the reason is only about the model.

## Slice(s)
### S1 (tests A1)
Method: Two things, same visit, order mixed per person. First: a 3-minute demo of the model the firm already uses (unknown which — do not name a vendor). Second: the live client board, no pitch. Each person picks one and writes why. We score reasons with a list they do not see: gating/proof words vs model-only words.
Type: Value
Execution: Requires manual run
Scope / time-box: 5 people. 15 minutes each. No new product.

## Signal
Success signal: 4 or more of 5 pick the board and mention gating, proof, or a slice in the reason.
Failure signal: 2 or more of 5 pick the model, or pick the board with a model-only reason.
Threshold: If it fails, pause more investment in ADLC as a wrapper until we have a different value claim. If it passes, value is not only the model in this sample. That is not a sale (see G5).
